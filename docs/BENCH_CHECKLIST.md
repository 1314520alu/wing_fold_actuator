# 台架验收清单

对应设计文档 §5.2 测试阶梯与 §5.3 验收标准。硬件到位后逐项勾选。

## 前置条件

- [ ] 舵机 VBAT 独立供电；MCU 3.3 V；舵机、MCU、飞控共地
- [ ] 半双工缓冲已接 USART1；编码器 USART2 通信正常
- [ ] 固件已烧录（`wing_fold_actuator.hex`）；CLI（USART3 115200）可连

## 四步验收（设计 §5.2）

### 1. 台架无负载

- [ ] CLI `motor` 点动正/反向，编码器 count 连续变化
- [ ] `cal a` → 点动到折叠端 A → `cal b` → 点动到端 B → `cal save`
- [ ] `cal show` 打印 A/B 与当前 count

### 2. PWM 发生器

- [ ] 1000–2000 µs 缓慢扫描，目标 count 线性变化，死区内停稳
- [ ] 运动中拔 PWM：150 ms 内速度归零，LED HOLD（1 s 周期）
- [ ] 恢复 PWM 后继续跟踪

### 3. 装丝杆慢速全行程

- [ ] 将 `vmax` 降至约 400（首版默认 800 的一半）
- [ ] 全行程往返，无机械干涉、异常发热或硬顶死
- [ ] 两端保留软件死区；必要时重新 `cal a/b` 略缩行程

### 4. 接飞控舵机通道

- [ ] 地面折叠指令脉宽与 Mission Planner / 参数一致
- [ ] 丢信号时保持位置（HOLD），恢复后继续

## 验收标准（设计 §5.3）

- [ ] 无合法 PWM：保持，电机速度为 0
- [ ] 标定后脉宽与 count 线性对应，死区内停稳
- [ ] 编码器通信失败：故障 HOLD，不持续盲转
